# 제목 후킹 패턴 리포트

- 분석한 제목 수: 3
- 평균 길이: 21.3자 (중앙값 21자)
- 구체적 금액 포함 비율: 67%
- 질문형 비율: 0%

## 요소별 사용 비율

- **관계인물** 67% — 여친(1), 친구(1)
- **돈이슈** 100% — 축의금(2), 데이트 통장(1), 반반(1), 택배(1)
- **감정반응** 67% — 정떨어(1), 입장 차이(1)
- **궁금증장치** 100% — 하자는 말(1), 둘러싼(1), 보낸(1)

## 자주 쓰인 조합

- 감정반응 + 관계인물 + 궁금증장치 + 돈이슈: 1회
- 감정반응 + 궁금증장치 + 돈이슈 + 구체금액: 1회
- 관계인물 + 궁금증장치 + 돈이슈 + 구체금액: 1회

## 후킹 강도 높은 제목 예시

- (4점) 데이트 통장 반반하자는 말에 정떨어진다는 여친
- (4점) 축의금 5만원을 둘러싼 입장 차이
- (4점) 축의금 3만 원 냈던 친구가 보낸 택배
