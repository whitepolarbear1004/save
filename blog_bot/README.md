# 생활경제 블로그 자동화

잘 되는 블로그의 **제목 패턴**(관계 인물 + 돈 이슈 + 감정 반응 + 궁금증 장치)을 분석합니다.
그 패턴으로 **새 글** 초안을 쓰고, 발행 전에 점검합니다.
참고 블로거의 본문은 수집하지 않고, 입력으로도 쓰지 않습니다.

## 설치

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=발급받은_키
```

## 사용 순서

```bash
# 1. 참고 블로그 제목 수집 (본인 PC에서 실행)
python collect.py sdedy rmsgud2007

# 2. 제목 패턴 분석 -> data/patterns.md
python patterns.py

# 3. 참고 자료 준비 (통계, 제도 등. 출처를 같이 적어두세요)
#    예: data/facts_축의금.txt

# 4. 초안 생성 -> output/날짜_주제.md
python generate.py --topic "축의금" --keyword "축의금 적정 금액" --facts data/facts_축의금.txt

# 5. 발행 전 점검 (키워드 횟수, 소제목, 문단 길이, 가상 사례 표기, [확인 필요] 남은 곳)
python check.py output/2026-09-29_축의금.md --keyword "축의금 적정 금액"
```

6단계는 직접 합니다. 초안을 읽고 [확인 필요] 부분의 수치를 채운 뒤 네이버 에디터에 붙여넣어 발행하세요.
자동 발행 매크로는 계정 제재 사유라서 넣지 않았습니다.

## 글 작성 규칙 (generate.py에 들어 있음)

- 제목: 구체적 금액 + 관계 인물 + 감정 반응으로 후킹합니다. 단, 본문에 없는 내용은 약속하지 않습니다.
- 서론의 갈등 장면은 가상 사례로 씁니다. 실화나 제보라고 하지 않습니다.
- 본론: 양쪽 입장을 보여주고 실제 경제 정보(평균, 계산법, 해결책)를 담습니다.
- 결론: 독자에게 질문을 던져 댓글을 유도합니다.
- 키워드는 6회 이하, 짧은 문단, 문단 사이 빈 줄.

축의금 / 조의금 금액, 데이트 통장, 더치페이, 부모님 용돈, 명절 비용 분담, 결혼 비용·혼수·예단,
신혼 생활비 통장 합치기, 친구 돈 빌려주기, 회식비·밥값 계산, 전세 보증금 분쟁, 상속·유산 분배
